# 평가 검토실

브라우저에서 평가 자료를 추출하고 OpenAI Responses API로 검토하는 Vite + React + TypeScript 앱입니다. 서버나 프록시 없이 정적 배포할 수 있습니다.

## 로컬 실행

```sh
npm install
npm run dev
```

검증 명령은 `npm test`, `npm run lint`, `npm run build`입니다.

## 사용자 흐름

1. OpenAI API 키를 암호 입력란에 붙여 넣습니다. 키는 React 메모리 상태로만 유지됩니다.
2. PDF, DOCX, XLSX/XLS, HWPX, TXT, MD, JSON, CSV 파일을 추가하거나 파일을 드롭합니다. 폴더 선택 버튼으로 디렉터리를 통째로 고를 수도 있습니다. `01_규정`, `02_판정대상`, `03_가상서류` 경로는 검토 프롬프트에 함께 전달됩니다.
3. 모델과 선택적 추가 지침을 확인한 뒤 검토를 시작합니다.
4. 판정, 가점, 누락·보완, 보고서 탭을 검토하고 Markdown 또는 JSON으로 내보내거나 보고서/메일을 복사합니다.
5. 작업 후 키 지우기 또는 초기화 버튼을 사용합니다. 샘플로 체험은 명확히 표시된 로컬 데모 자료만 사용하며 API를 호출하지 않습니다.

## 보안 모델과 데이터 처리

- 문서 파싱과 점검은 브라우저에서 실행됩니다. 업로드 파일을 앱의 서버로 보내는 기능은 없습니다.
- API 키는 React 컴포넌트 메모리에만 보관하며 localStorage, URL, 서버, 앱 로그에 기록하지 않습니다. OpenAI 직접 요청의 `Authorization` 헤더 외에는 키를 사용하지 않습니다. 페이지를 새로 고침하거나 초기화하면 상태에서 제거됩니다.
- 실제 검토 시 문서 텍스트와 지침은 브라우저에서 `https://api.openai.com/v1/responses`로 직접 전송됩니다. 이 서비스 이용 및 보존 정책은 사용자의 OpenAI 계정 설정에 따릅니다.
- API 키를 사용하는 동안 브라우저 확장 프로그램이나 이 장치의 다른 접근 주체를 앱이 통제할 수는 없습니다. 신뢰하는 브라우저에서 사용하세요.

## 파싱 및 제한

- PDF: pdfjs-dist의 페이지 텍스트
- DOCX: JSZip/XML 기반 기본 문단·표 텍스트 추출
- HWPX: 압축된 section XML의 기본 텍스트 추출
- XLSX/XLS: SheetJS 시트별 CSV 텍스트
- TXT/MD/JSON/CSV: UTF-8 텍스트
- HWP 바이너리 형식은 지원하지 않습니다. HWPX도 기본 텍스트만 추출하며 도형, 복잡한 레이아웃, 이미지 속 글자는 포함되지 않습니다. PDF 이미지의 OCR도 제공하지 않습니다.
- 파일 하나당 25 MB 제한입니다. 추출 텍스트가 매우 크면 브라우저/API 한도에 걸릴 수 있으며 앱은 120,000 토큰의 대략적 전송 전 경고 한도를 적용합니다. 예상 토큰 수는 문자 수 기반 추정치입니다.
- O는 조건 충족·적합, X는 조건 미충족·부적합, 보류는 정보 부족·계산 불가를 뜻합니다. 보류는 확정된 결함으로 취급하지 않으며 사유가 필수입니다. 점수와 보고서는 AI 초안이므로 공식 판정 전에 원자료를 확인해야 합니다.

## Vercel 배포

저장소를 Vercel에 연결하고 기본 빌드 명령 `npm run build`, 출력 폴더 `dist`를 사용하세요. 포함된 `vercel.json`은 클라이언트 경로를 SPA 진입점으로 재작성합니다. API 키를 빌드 변수나 Vercel 환경 변수로 등록하지 마세요. 이 앱은 런타임 백엔드를 사용하지 않습니다.
